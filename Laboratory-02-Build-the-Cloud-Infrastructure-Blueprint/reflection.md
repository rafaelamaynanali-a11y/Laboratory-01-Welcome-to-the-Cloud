# Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?
I believe **Compute Resources** are the most important component. While storage and networking are essential, nothing can run or function without processing power. Compute resources — specifically the CPU and memory — act as the "brain" of the entire infrastructure. Whether hosting websites, running databases, or processing data, every service ultimately depends on compute capability. Without compute, even the best storage and networking are just empty shells.

## 2. How does Linux support cloud computing?
Linux forms the foundation of cloud computing because it is lightweight, secure, stable, and completely free. Almost all cloud servers worldwide run Linux because it can be customized to do exactly what is needed without unnecessary features. It also supports every major cloud tool, container technology, and programming language, making it the universal operating system of the cloud.

## 3. Why is technical documentation important before deploying infrastructure?
Documentation acts as a blueprint and a guide. Before deploying anything, clear documentation ensures that everyone understands what is being built, why, and how it connects together. It prevents mistakes, makes future maintenance easier, and provides a reference if something breaks. Without documentation, even the best-designed infrastructure becomes difficult to manage, scale, or hand over to another team.

I learned how to inspect a live Linux server using command-line tools to discover real hardware and system information. I also learned how to write professional technical documentation using Markdown, how the three major cloud providers compare in their services, and how to design a simple cloud architecture diagram. Most importantly, I learned how to organize, commit, and maintain a structured project portfolio on GitHub.
