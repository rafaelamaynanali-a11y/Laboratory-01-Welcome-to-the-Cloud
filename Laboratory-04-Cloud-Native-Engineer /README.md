# Laboratory 04 – The Cloud-Native Engineer

## Mission Overview
This laboratory activity introduces containerization — the modern cloud-native approach to deploying applications. Using Docker in the KillerCoda Playground, the difference between traditional Virtual Machines and lightweight Containers is explored. An Nginx web server is deployed as a container, managed through its lifecycle, and documented to demonstrate how cloud-native engineering works.

## Objectives
- Differentiate Virtual Machines from Containers.
- Verify Docker installation and status.
- Pull, run, and access a containerized web server.
- Manage containers through start, stop, and remove operations.
- Maintain a professional GitHub Cloud Computing Portfolio.
