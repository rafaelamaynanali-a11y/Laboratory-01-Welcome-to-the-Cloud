## Part 3 — Analysis Questions

**1. Which cloud provider offers the broadest range of services?**
AWS offers the widest selection with over 200 services across every category, from compute to specialized analytics and enterprise tools. Its long market leadership has allowed it to build the most complete ecosystem for nearly any use case.

**2. Which provider best integrates with Microsoft technologies?**
Microsoft Azure is designed to work natively with Windows Server, Active Directory, and Microsoft 365. Organizations already using these tools can migrate to Azure with minimal reconfiguration, making it the natural choice for Microsoft-based environments.

**3. Which provider is strongest in Artificial Intelligence and Kubernetes?**
Google Cloud Platform leads in both areas — Google invented Kubernetes and offers the most mature managed implementation through GKE, while its AI tools leverage the same technology behind Google Search, giving it an edge in advanced machine learning.

**4. Which cloud platform would you personally choose and why?**
I would choose AWS because it balances comprehensive service coverage with strong community support and career relevance. Learning AWS opens the most opportunities, and its documentation plus free-tier programs make it very accessible as a student while remaining powerful enough for future enterprise projects.
