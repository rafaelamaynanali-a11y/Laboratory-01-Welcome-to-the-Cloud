# Microsoft Azure Research

## Brief Overview
Microsoft Azure is a cloud computing platform launched in 2010, built on Microsoft's enterprise software heritage. It provides IaaS, PaaS, and SaaS solutions and integrates deeply with Microsoft products including Windows Server, Active Directory, and Microsoft 365.

## Global Infrastructure
- **60+** geographic regions — most regions globally
- Paired regions within each geography for disaster recovery
- Strong presence in government and sovereign clouds

## Cloud Management Console
- Unified portal at **portal.azure.com**
- Blade-based interface organized by resource groups
- Deep integration with Microsoft Entra ID (formerly Azure AD)

## Four Core Services
1. **Azure Virtual Machines** — On-demand scalable compute supporting Windows and Linux.
2. **Azure Blob Storage** — Scalable object storage for unstructured data.
3. **Azure SQL Database** — Fully managed relational database service.
4. **Azure Virtual Network (VNet)** — Secure, isolated network environment in the cloud.

## Three Advantages
1. **Seamless Microsoft integration** — Best choice for organizations already using Windows, Active Directory, and Office 365.
2. **Broad regional coverage** — Largest number of regions worldwide, excellent for international compliance.
3. **Hybrid capabilities** — Strong tools for connecting on-premises infrastructure to the cloud.

## Typical Enterprise Use Cases
- Enterprises migrating from Windows Server environments
- Government and educational institutions
- Organizations using the Microsoft 365 ecosystem
- Hybrid and multi-cloud deployments
