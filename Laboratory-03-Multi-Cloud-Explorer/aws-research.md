# Amazon Web Services (AWS) Research

## Brief Overview
Amazon Web Services (AWS) is the world's largest and oldest public cloud platform, launched in 2006. It offers over 200 fully-featured services spanning compute, storage, databases, networking, AI, and analytics. AWS serves millions of customers globally, from startups to Fortune 500 companies.

## Global Infrastructure
- **32** geographic regions worldwide
- **102** availability zones
- Extensive network of edge locations for low-latency content delivery
- Most mature and widely distributed global footprint

## Cloud Management Console
- Web-based dashboard at **console.aws.amazon.com**
- Centralized view of all services
- Customizable dashboard layout
- Built-in search, billing monitoring, and access controls

## Four Core Services
1. **Amazon EC2** — Elastic Compute Cloud: Scalable virtual servers in the cloud.
2. **Amazon S3** — Simple Storage Service: Highly scalable object storage for files, backups, and data.
3. **Amazon RDS** — Relational Database Service: Managed databases including MySQL, PostgreSQL, and SQL Server.
4. **Amazon VPC** — Virtual Private Cloud: Isolated network environment to run resources securely.

## Three Advantages
1. **Widest service selection** — Deepest ecosystem of tools across every category.
2. **Mature ecosystem & market leadership** — Largest community, documentation, and third-party integrations.
3. **Enterprise reliability** — Proven track record with high availability and compliance certifications.

## Typical Enterprise Use Cases
- Global e-commerce platforms
- Enterprise SaaS applications
- Big data analytics and data lakes
- Media streaming and content delivery
