# Laboratory 05 – The Cloud Data Engineer

## Mission Overview
This laboratory activity introduces Object Storage — the scalable, cost-effective foundation of modern cloud data systems. Using Docker, a MinIO S3-compatible storage server is deployed to demonstrate how cloud-native applications store images, backups, and unstructured data. A test bucket is created, files are uploaded via the web console, and the entire process is documented to support a photo-sharing application design.

## Objectives
- Differentiate between Block, File, and Object Storage.
- Deploy an S3-compatible MinIO server using Docker.
- Access a cloud service through port mapping in a web browser.
- Create a storage bucket and upload files via the web interface.
- Maintain a professional GitHub Cloud Computing Portfolio.

## Tools Used
- KillerCoda Ubuntu Playground
- Docker Engine
- MinIO Object Storage
- GitHub
- Markdown

## Skills Learned
- Recognizing when to use Object Storage over traditional storage types.
- Passing secure configuration values to containers using environment variables.
- Accessing web-based administration tools through specific network ports.
- Designing scalable storage infrastructure for unstructured data.
